# Reference artifacts from the mock device

These headers were generated by `pc/train.py` from **synthetic** data produced
by `tools/mock_device.py`, not from a real camera. They are kept here as a
worked example of what `train.py` emits and so that
`tools/verify_export.py` has something to check.

**Do not flash them.** A model trained on synthetic trajectories will
confidently misclassify real gestures, which is worse than no model: the
firmware will look like it is working while being wrong.

To use them on the mock:

```bash
cp data/mock-generated/{model.h,labels.h,golden_vector.h} src/
python3 tools/mock_device.py --port 8099 &
python3 pc/check_device.py --url http://127.0.0.1:8099
```

To use your own, record a real dataset and run `make train`, which writes the
same three files into `src/`.
